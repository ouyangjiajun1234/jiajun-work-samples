Built for movement.

Stride is an original sports-app interface sample by Jiajun, made with AI assistance. It is a fictional portfolio concept, not a commissioned client project.

  • Try the timer, pause/resume, completion animation, session list and weekly goal.
  • The completion animation is an original Lottie JSON file, rendered with lottie-web 5.13.0.
  • All activity data and the illustrated route are fictional. No account, GPS, sensor, payment, model or analytics is connected.
  • The HTML preview uses the free cdnjs player and requires an internet connection. A production app needs separate API, platform and format testing.
