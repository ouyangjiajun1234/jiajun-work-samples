Meet Afterglow.

This is a fictional companion-chat interface, designed and built as a working frontend sample by Jiajun with AI assistance. It is not a commissioned client project.

Try the three rooms, send a message, or save a keepsake. Replies are scripted to demonstrate the interaction. No live AI, accounts, payments, or analytics are connected. Only saved notes and the room preference use this browser's local storage.

A production version would need the client's real content, API integration, privacy requirements, and testing.
