A static personal portfolio of original AI-assisted demos. No customer work, payments or claimed revenue are shown.

- Afterglow: standalone HTML/CSS/JavaScript chat UI with scripted responses, themes and saved snippets. No live AI API.
- Stride: HTML/CSS/JavaScript fitness UI with fictional data and an original Lottie completion animation. The free CDN player requires internet. No sensors, GPS or production backend.

Open index.html locally or browse the public GitHub Pages site. Contact links open the user's email client or the existing Fiverr service; this site has no checkout, account creation or data upload.
